# SPOT dashboard — shorter source

## Open in VS Code

1. Extract the ZIP.
2. Open the extracted `spot-dashboard` folder in VS Code.
3. Open `index.html` to see the page markup.
4. Double-click `index.html` in File Explorer to run the dashboard in a browser.

Keep the files in the same folder. No installation or build step is required.

## Files to edit

- `index.html`: Page structure. The large embedded image and sample data have been removed from this file.
- `styles.css`: Colors, layout, and responsive styles.
- `app.js`: Buttons, waypoint selection, mission details, result filters, and replay.
- `fictional_floor_plan.png`: Your original floor-plan image.
- `sample-data.js`: The reference sample mission records. You can leave this file alone when changing the layout.

Save changes with Ctrl+S, then refresh the browser.

This is the same dashboard with the same 15 clickable waypoint pins and two-floor selector. The original floor-plan image is separate to keep the code readable. It remains a local prototype using sample mission data, without live telemetry or video.
